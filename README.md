# Pix2Struct TextCaps-base text-aware image captioning pipeline

DIMER inference and fine-tuning wrapper for **Pix2Struct fine-tuned on TextCaps** (`google/pix2struct-textcaps-base`), Google Research's 282M-parameter image-encoder/text-decoder that describes an image in one English sentence *quoting the text it reads from the pixels* (a sign, a label, a jersey number) without a separate OCR step — pinned to an immutable Hugging Face revision and loaded only from a digest-verified local snapshot. The pipeline accepts one image and an optional caption prefix, decodes greedily under a caller-owned token budget, and returns the caption string with a `truncated` flag; it returns no score, no transcript and no location. It also carries a bounded adaptation contract: `adapt` fine-tunes the caption decoder's last blocks and final layer norm on a validated `{id, image, captions}` dataset over encoder outputs computed once, `evaluate` scores a held-out split with BLEU-4, ROUGE-L, CIDEr-D and unigram F1 beside two non-neural baselines, and `save_artifact` / `from_artifact` export and reload the trained tensors as a safetensors adapter bound to the pinned base.

## Upstream alignment

- Model: `google/pix2struct-textcaps-base`
- Revision: `61bee0d7e2378e601b68f853ceee4f7cf99f1b88`
- Upstream weight license: Apache-2.0
- Upstream task: image captioning with reading comprehension (TextCaps)
- Repository adaptation: bounded supervised fine-tuning of the caption decoder's last *k* blocks plus its final layer norm (`adapt`; the image encoder, embeddings and untied `lm_head` stay frozen); the tutorial's default corpus is VizWiz-Captions (`mm-eval/VizWiz-Captions` @ `c4a6d897836e7885d0095134f92d392e4e770539`, CC BY 4.0), read column-only plus one row group of photographs with per-file digests at run time — the BLIP captioning row's sample, reused

## Quick start

```python
from PIL import Image
from pix2struct_textcaps_pipeline import Pix2StructTextCapsPipeline, text_recall

pipe = Pix2StructTextCapsPipeline.from_pretrained()        # stages + verifies weights/pix2struct-textcaps-base first
result = pipe.caption(Image.open("storefront.jpg"))         # unconditional
print(result["caption"], result["new_tokens"], result["truncated"])   # generated text; no score exists

# check whether text you know is in the image was quoted (a plumbing check, not a caption metric)
print(text_recall(result["caption"], ["Blue Fern Bakery", "OPEN"]))

result = pipe.caption(Image.open("storefront.jpg"), prefix="A picture of")   # conditional (upstream README example)
```

Install into a Python 3.12 environment that already holds the pinned dependencies with `pip install -e . --no-deps`; run `pytest -q -o addopts= tests` for the offline test suite (no weights needed). On a fresh clone the manifest is committed but the weights are not: `Pix2StructTextCapsPipeline.from_pretrained(allow_download=True)` fetches exactly the missing manifest-listed files at the pinned revision, then verifies them.

## Weights layout

```
weights/pix2struct-textcaps-base/
  dimer-base-manifest.json   # modelId, revision, per-file bytes + SHA-256 (8 files)
  config.json                # Pix2StructForConditionalGeneration: 12-layer ViT encoder + 12-layer text decoder
  preprocessor_config.json   # max_patches 2048, 16x16 patches (not the VQA variant: no header rendering)
  special_tokens_map.json  spiece.model  tokenizer.json  tokenizer_config.json
  model.safetensors          # git-ignored, 1,129,177,976 bytes
  README.md
```

`pytorch_model.bin` exists upstream and is deliberately not listed (pickle; DIMER does not accept `.bin`).

## Input ceilings and request parameters

`MIN_IMAGE_SIDE = 16`, `MAX_IMAGE_SIDE = 4096`; `MAX_PREFIX_CHARS = 128` (optional prefix, whitespace collapsed); `MAX_NEW_TOKENS = 64`, `DEFAULT_MAX_NEW_TOKENS = 30`; `DECODING = "greedy"`; `MAX_PATCHES = 2048` (the processor's patch budget, documentation only). See `MODEL_CARD.md` for who owns the budget and prefix, why `text_recall` is not a caption metric, and the measured CPU timings.

## Tutorials

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/kurtvalcorza/pix2struct-textcaps-pipeline/blob/main/tutorials/pix2struct_textcaps_colab.ipynb)

`tutorials/pix2struct_textcaps_colab.ipynb` is declared `E2E` / `GUIDED` under DIMER Notebook Specification 2.0 and is **standalone** (§4): generated by `tools/build_notebook.py`, it carries the three pipeline modules (`pipeline.py`, `metrics.py`, `samples.py`), model identity, manifest digests and runtime pins, so the exported notebook runs without this repository (parity enforced by `tests/test_notebook_parity.py`). Its default `Run all` path resolves the pinned model through the carried staging and verification path, reads the text columns of one pinned VizWiz-Captions shard column-only and the 336 photographs of its first row group in one digest-checked range read, validates and splits them by image (208 / 40 / 70), captions three cartoon scenes with known text drawn in code through `validate_inputs` and `caption` with `text_recall` as sanity evidence, scores the frozen model on the test photographs beside the constant-caption and colour-nearest-neighbour baselines (BLEU-4, ROUGE-L, CIDEr-D, unigram F1, per `text` / `no-text` category), fine-tunes the caption decoder's last two blocks and final layer norm with validation-CIDEr-D epoch selection, scores the held-out split again (the gain is recorded as `adapted_beats_frozen`, not asserted), re-captions the scenes, and exports a safetensors adapter that it reloads with verified parity — one seeded split of one corpus, no benchmark claim. BYOD (one zip of images plus `records.jsonl`) is optional and gated off by default. See `tutorials/README.md` for the registry and `docs/release-verification.md` for the release gate.
